# 🍔 Online Food Ordering System

A full-stack web application for ordering food online, built with Python, Flask, and SQLite.

## ✨ Features
* **User Authentication:** Sign up and log in securely.
* **Interactive Menu:** Browse delicious food items sorted by categories.
* **Cart System:** Add items to cart and manage orders dynamically.
* **Database Driven:** Integrated with SQLite to store users, menu items, and cart data.

## 🛠️ Tech Stack
* **Backend:** Python, Flask
* **Frontend:** HTML5, CSS3, Jinja2 Templating
* **Database:** SQLite3
* **Production Server:** Gunicorn
